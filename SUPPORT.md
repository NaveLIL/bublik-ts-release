# Поддержка

Для обычной ошибки используйте форму **Bug report**. Для предложения — **Feature request**. Уязвимости отправляйте только по инструкции из [SECURITY.md](SECURITY.md).

К отчёту об ошибке приложите:

- версию Bublik и digest образа;
- версию Docker/Compose и операционную систему;
- состояние healthcheck;
- точные шаги воспроизведения;
- короткий фрагмент логов без секретов и персональных данных.

Не публикуйте `.env`, Discord-токен, пароль PostgreSQL, содержимое Redis, резервные копии и полные списки участников сервера.
