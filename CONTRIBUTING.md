# Участие в проекте

Этот публичный репозиторий содержит distribution-версию Bublik: обфусцированный runtime, миграции, конфигурацию запуска и документацию. Исходный TypeScript разрабатывается и проверяется отдельно.

## Что можно предложить

- воспроизводимый отчёт об ошибке;
- улучшение документации или примеров конфигурации;
- предложение функции;
- исправление безопасной эксплуатационной конфигурации.

Pull request с исходным кодом модулей или вручную изменёнными файлами `dist-protected/` не принимается. Runtime-артефакт экспортируется только из проверенного source-релиза и должен совпадать с manifest.

## Перед pull request

1. Не добавляйте `.env`, токены, дампы, логи и пользовательские данные.
2. Ограничьте PR одной задачей.
3. Объясните причину и влияние изменения.
4. Выполните доступные проверки из README.
5. Для уязвимостей следуйте [SECURITY.md](SECURITY.md), а не открывайте публичный PR.
